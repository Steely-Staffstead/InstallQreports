    Installation and updates

    Deployment model

    QReports is published as a VSTO ClickOnce application. setup.exe checks prerequisites and registers the Excel add-in for the current user. The .vsto manifest identifies the application files and published version.

    Requirements

    • Microsoft Excel desktop on Windows;
    • .NET Framework 4.8;
    • Microsoft Visual Studio Tools for Office Runtime;
    • access to the publication site when installing/updating;
    • access to database/API endpoints configured by the organization.

    Install

    1. Close Excel.
    2. Open the approved QReports installation URL.
    3. Run setup.exe.
    4. Accept ClickOnce/VSTO trust prompts allowed by organizational policy.
    5. Open Excel and verify that QRep appears.
    6. Open QRep > Settings > License Status to verify entitlement.

    Updates

    ClickOnce updates are enabled and the GitHub Pages installation site is the configured source. Excel may check the deployment manifest when the add-in starts. Close all Excel processes before updating so no old assembly remains loaded.

    For managed environments, allow-list the publication URL and validate the release signing certificate. Test with the organization's Excel version, bitness, security baseline, and endpoint protection before broad deployment.

    Troubleshooting deployment

    • Check Excel > File > Options > Add-ins for disabled/inactive add-ins.
    • Under Manage: COM Add-ins, verify QReports is enabled.
    • Confirm VSTO Runtime and .NET Framework 4.8 are installed.
    • Close every Excel process and retry.
    • Use QRep > Settings > About to copy environment and assembly-path information.
    • Review Troubleshooting.
