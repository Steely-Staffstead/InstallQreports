    Canvas tool

    Premium/Pro feature: Canvas requires the Canvas Tool feature in the QReports license. It is available in the applicable Premium/Pro package. PowerPoint integration additionally requires the PowerPoint add-in feature.

    QReports Canvas creates multi-page visual reports from queries, tables, measures, parameters, charts, and formatted tiles. The same Canvas editor is used from Excel and PowerPoint, so a visual definition follows the same query and parameter rules in both hosts.

    Open Canvas

    From Excel, choose QRep > Qanvas Tool. You can also right-click a supported QReports shape or picture and choose Open in Qanvas tool.

    From PowerPoint, choose QReports > New Canvas, select an existing Canvas shape and choose Edit Selected, or use the shape context menu. See PowerPoint add-in.

    Canvas can also open and save standalone .qrcn files. A .qrcn file stores the report definition; runtime result tables are refreshed from their sources.

    Edit mode and view mode

    • Edit mode lets you add, select, move, resize, duplicate, order, configure, and delete tiles.
    • View mode is intended for interacting with the finished report, including parameters and filters.

    Use the Edit mode button to switch modes. Right-click a tile for Edit, Duplicate, Send to Back, Bring to Front, Remove, Edit own query, or Refresh data, depending on the tile type.

    Pages and page data

    Each Canvas page can have its own name, appearance, size, background, query, filters, and result table. Add pages with New Page. Page tabs can be renamed, reordered, or removed.

    The Page Query area provides data shared by tiles on that page:

    Source type Purpose
    Source Runs SQL against a saved connection.
    Canvas Runs Mini SQL against tables published by Canvas tiles.
    API Reserved for API-backed page queries; availability can depend on the application version.

    Use Edit query to open Query Tool, Measures to manage Mini DAX measures, and Update to refresh the current page result. The Data tree shows fields available to page tiles.

    Parameters are patched before SQL or Mini SQL is executed. This is the same parameter resolver used by Query Tool and the Excel add-in.

    Tile types

    Tile Typical use
    Table Detailed rows with selected columns, headers, totals, and formatting.
    Matrix Grouped and hierarchical data with measures, totals, and conditional formatting.
    Chart Visual analysis using the shared QReports chart designer.
    Card A prominent KPI value with caption, comparison, or delta.
    Text Titles, explanations, dynamic parameter text, and annotations.
    Picture Logos, icons, illustrations, and other image content.
    Parameter An interactive parameter control placed directly on the report.

    Table, Matrix, and Chart tiles can use the page data or their own query, depending on the design. A table or matrix can publish a named result that another Canvas Mini SQL query can use.

    Create a first Canvas report

    1. Open Canvas and add or rename the first page.
    2. Choose the page source and use Edit query to retrieve data.
    3. Refresh the page query and confirm that fields appear under Data.
    4. Add a Table tile and select the fields to display.
    5. Add a Chart or Card using the same page data.
    6. Resize and align tiles in Edit mode.
    7. Add parameters or filters when the report needs interaction.
    8. Switch to View mode and test the report.
    9. Save or return the Canvas to its host.

    Tables and matrices

    Double-click a table or matrix, or use its design command, to configure fields, hierarchy, measures, column widths, number formats, visibility, totals, and conditional formatting.

    Matrix conditional formatting can use a measure that returns a named color, hexadecimal color, or RGB value. Always reopen a tile after saving to confirm that its stored definition contains the intended layout and formatting.

    Charts

    Chart tiles use the shared Chart tool. Select categories and series, then configure labels, axes, gridlines, colors, markers, lines, and chart-specific options.

    When a chart is saved back to Canvas, both its visible rendering and JSON definition are stored. Reopening Design Chart should restore the editor from that definition.

    Parameters and filters

    Canvas uses the shared parameter model: text, lists, hierarchical multi-select trees, date pickers, numeric inputs, formatting, and text parsing.

    • In Excel-hosted Canvas, parameters are refreshed from the workbook _control sheet.
    • In PowerPoint, parameters are stored with the presentation and can refresh all Canvas shapes.
    • A Parameter tile lets the report user change a value without opening the separate input form.
    • Page and visual filters can restrict the displayed data after the page query is loaded.

    Use the same {{parameter}} syntax in SQL, Mini SQL, text, and supported visual definitions.

    Refresh commands

    Command Effect
    Update Refreshes the current page query.
    Refresh data Refreshes the selected tile's own query.
    Refresh Multi Refreshes published Canvas sources used by other queries.
    Refresh All Refreshes all applicable Canvas data and visuals.

    Use a small page-level query where several visuals need the same data. Use an own query when a tile needs a different source, aggregation, or refresh path.

    Layout, appearance, and export

    Canvas supports preset or manual page sizes, zoom, solid or gradient backgrounds, background images, rounded page appearance, and configurable tabs. Use Zoom in, Zoom out, or Reset zoom to 100% while editing.

    The File menu can save a .qrcn definition, open a previous file, maintain recent files, export the current canvas to PNG or JPG, and copy the rendered canvas image to the clipboard.

    Return to Excel

    When hosted by Excel, Return stores the Canvas specification with the workbook shape and replaces or inserts its rendered image. Loading the worksheet can refresh stored Canvas shapes after their source data changes.

    Keep the underlying workbook connections, _control parameters, and report code with the workbook. The rendered picture is only the visible result; the stored Canvas JSON is required for later editing.

    Use Canvas in PowerPoint

    The PowerPoint add-in opens the same Canvas editor and returns the result as a picture on the slide. The Canvas JSON is stored with that picture so it can be edited and rerendered later.

    PowerPoint provides New Canvas, Edit Selected, Load selected, and Parameters. Loading rerenders selected or all stored Canvas shapes from their definitions. See the PowerPoint QRep Ribbon.

    Current considerations

    • Test queries in Query Tool before building a large visual page.
    • Large images and many detailed tiles increase rendering time and file size.
    • Keep connection credentials out of Canvas text and screenshots.
    • API-backed page-query behavior can vary by version; API Explorer and Query Tool remain the supported definition path.
    • A rendered image without its stored Canvas definition cannot be reopened for full editing.

    Continue with Query Tool, Parameters, Chart tool, or PowerPoint add-in.
