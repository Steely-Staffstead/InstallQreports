    Changelog

    User-visible changes are grouped by calendar week. Dates identify the Monday-to-Sunday period in which the work was completed.

    WEEK44

    26 October–1 November 2026

    List forms and smoother shared registration

    • Added List Form, a new List view that shows and edits one record at a time. It is useful for test cases, tasks, findings and other registrations with many fields.
    • Made forms easy to arrange visually. Choose the number and width of columns, move fields in the preview, and let a field span several columns or rows. Long text, dates, choices, checkboxes, numbers, sliders and links use controls suited to their field type.
    • Added compact field settings, read-only fields, default values and a selected-row highlight. A normal List can act as the selector while a Form view shows the selected record from the same source.
    • Improved shared Lists so a linked List reuses the existing embedded source instead of creating an extra empty source. Lists and forms can therefore share one central register across pages.
    • Fixed List filters and record selection in Presentation mode so they follow the same values and single-selection rules as Edit mode.
    • Polished List and Form layout: headers and values align correctly, alternating row bands fill the full width, one-row and multi-row text boxes keep readable labels, and URL fields show their friendly screen tip instead of the stored address.
    • New pages now show nine distinct page layouts, including Overview + details, Dashboard, Project plan, Four tiles, and List + details. Layouts wait for you to choose when to add content.
    • Fixed the installer header so dialog titles and explanations no longer overlap the Qvitr branding.
    • Improved Matrix subtotals. Bottom subtotals now use one clean total row by default, with the expand or collapse button on that row instead of repeating the group heading. The previous two-row style is still available, and the related settings are arranged in a clearer order.
    WEEK43

    19–25 October 2026

    Reusable report content, richer editing and faster source workflows

    • Added Qanvas-to-Qanvas import for complete editable pages, page and tile filters, related sources and selected measures. Sources can also be imported without pages, with footprint matching and explicit choices to reuse, replace, skip or create a separate source when definitions collide.
    • Added editable manual tables stored either inside a Qanvas file or as reusable local files. The grid supports row and column editing, column types, lookup values from other sources, a calendar lookup with optional time and ISO week numbers, column resizing/reordering, automatic row creation with Tab, and conversion between embedded and file storage.
    • Added a dedicated editable List tile on top of the embedded manual-table model. New Lists offer Basic and Task presets with stable IDs, automatic line numbers and created/updated timestamps; typed custom fields, code/label choices, source lookups, and safe external/document-page URL fields; search, sorting, row move/duplicate/delete/complete actions; theme roles; and a live movable/resizable designer. Fields can be reordered by drag or compact move controls, columns can be resized directly, and new-row defaults support choices, booleans, Today and current date/time. Embedded Lists can be exposed as ordinary datasources, copied with independent owned data, and optionally edited in Presentation mode, while linked sources and web exports remain read-only.
    • Expanded List appearance and interaction controls with optional title/search text, left/right search alignment, separate header, row, grid-line and column-separator colors, square or rounded headers, alternating rows, theme-aware URL hover surfaces, and calendar/dropdown controls that inherit row text and surface colors. URL screen tips now act as the readable link label and tooltip, internal page links navigate correctly, and Add row plus row action controls work in Presentation mode when editing is enabled.
    • Added an instant in-Qanvas source-data viewer and consolidated source actions for viewing data, editing queries or measures, links, rename and delete without reloading an already cached preview.
    • Expanded Report Grid copy, paste and repeat behavior. Cell aggregation, fields and measures now copy with the cell; one copied cell can fill a multi-cell selection; and F4 repeats formatting, number formats, alignment, borders, dimensions, formulas, field/measure selections and row/column operations on a new selection. The right-click menu now groups Copy, Paste, Insert and Move commands into compact submenus while keeping their most common parent actions directly clickable. Locale-formatted numeric selections calculate correctly, and empty filtered values behave as zero in arithmetic.
    • Improved Report Grid formula editing: F2 now enters edit mode for values, formulas, fields and measure-backed cells, showing a readable measure expression in the cell and formula bar; Enter commits and Escape restores the original binding. Colored formula references can be dragged to another range while preserving relative and absolute-reference semantics.
    • Refined Report Grid sizing and selection with continuous explicit row heights, clipped single-line content by default, opt-in wrapping, vertical alignment, clearer row numbers around filter badges, and improved row/column filter editing.
    • Improved formatted text with reliable pasted tables, code blocks and whitespace-sensitive diagrams, an Insert table command, scroll-inside-box overflow, and inline images with alignment, proportional resizing and the same compression workflow as image tiles. A new readable datecountdown("date","future","today","past") function inserts configurable future, today and completed text that recalculates automatically without a measure and remains easy to edit, copy, and paste.
    • Improved Gantt task descriptions with page and external links, interactive checklists, preserved text when - or -- is converted to a list item, and visible navigation when an internal page link is followed. Task priorities support Low, Normal and High with configurable icons and theme-aware colors.
    • Added default Open, In progress and Completed Gantt statuses while retaining editable labels, and made embedded or local manual Gantt sources available through the normal table viewer.
    • Reworked the Gantt task inspector into a compact, saved-height bottom panel. Task and milestone, schedule/assignment, and status/progress/hours now use three dense rows; Task ID is a read-only reference and the multi-predecessor editor stays collapsed until requested. The inspector can be disabled for bar clicks, its spacing has been tightened further, and its surfaces, inputs, dropdowns, date controls and actions now follow the active Gantt theme. The predecessor editor is a normal button that opens a movable inspection dialog.
    • Added a simplified Gantt project toolbar, schedule-health panel, zoom/navigation controls and dependency editor. The task context menu now follows the Gantt theme, and appearance controls that do not apply to the selected input style are disabled instead of implying that they will affect it.
    • Improved charts with consistent tile/designer plot spacing, full-size treemap rendering, aligned value axes for multiples, reorganized doughnut controls with independent center/category typography, line breaks and safer ring-label placement, configurable rounded ends for bar and column charts, and an optional background-colored gap around line/scatter markers. Label spacing can always retain the first and/or last value, and markers can be limited to points that still have a visible label. Clicking a line or marker now opens Line & markers instead of Data labels; the Properties pane also exposes editable chart titles and the most-used line, marker and bar-layout controls.
    • Fixed direct chart-property refresh so Use canvas theme, background and gridline changes redraw immediately without reopening and reapplying the designer. Changing a line chart to a bar chart now preserves a visible plot, and duplicated charts retain independent, editable top positions instead of being constrained by stale geometry.
    • Added an Executive indigo report theme inspired by dark financial dashboards, with deep navy surfaces, warm cream accents, lavender text, green/red status roles and a matching eight-color chart palette.
    • Reorganized tile and graphic property groups, removed duplicate Content sections, kept Properties/Filters tabs visible while scrolling, and improved narrow-pane layouts and source action labels.
    • Added compact property-group shortcuts above the preview in Chart, Table, Matrix, Gantt and SVG designers, matching the existing Visual filter and Multi-card navigation. The shortcuts open collapsed groups, scroll to them and place keyboard focus on the selected section.
    • Recent Qanvas files are now deduplicated by path, and Settings controls how many entries are retained and shown, from 1 to 25 with a default of 10.
    • AI workspaces are now connected per report instead of through one global last-used pointer. Renamed or newly opened reports no longer inherit an unrelated workspace, new workspace copies use .qanvas, and the AI panel shows the selected engine plus the full open-report, workspace and working-copy paths.
    • Moved AI configuration to its own top-level Settings page and added Claude Code, Codex and GitHub Copilot guidance for current rich text, Gantt, local-table and Manual SVG authoring. Custom generated SVG now explicitly uses nested svgGraphic.template: "manual" on every provider turn, including resumed sessions.
    • Added a dedicated SVG designer with a collapsible reusable-template gallery, custom SVG analysis, editable text/typography/links and shape colors/borders, explicit category-slot bindings, and automatic Today/fixed/field/parameter date-marker placement on detected timeline axes. Clicking the preview selects the matching component control, and duplicating a detected date marker creates another independently configurable dynamic marker. Marker placement now moves only its own label, badge and line, including in existing duplicated SVGs, without shifting a containing background shape. Its live preview uses the same tile ratio and render path as the applied graphic. Text inputs now share the searchable token lookup for source fields, linked measures, parameters and functions, and preview selection no longer lets the fixed header or Apply/Cancel footer cover designer controls.
    • Added a Multi-card tile and designer. One reusable card layout can repeat by a dimension, show configurable field or measure values in columns, aggregate raw columns with First, Sum, Average, Min, Max or Count, and inherit the canvas theme or use explicit card colors and borders. The designer is also available from the tile's right-click menu and provides independent typography for headings, supporting text, values and captions. Calculated text columns now evaluate row by row before visual aggregation, fixing date/week captions that previously displayed NaN.
    • Multi-card value rows are now compact by default, with format, alignment, placement, cell display, data bars and conditional formatting under More. Conditional formatting can use a separate field/measure, repeated cards can show a conditional edge band, and caption/template inputs offer a right-click insert menu for fields, measures, parameters and text functions.
    • Upgraded the single Card tile with the same value/caption typography, placement, alignment, comparison, conditional icon/arrow and number-format controls used by Multi-card. Custom positive/negative/zero formats can retain an explicit + sign for positive values, and positive and negative conditional arrows can be configured independently.
    • Added visual filters on the canvas. Existing page filters and linked tile filters can be shown as responsive button groups, compact dropdowns, cards or multi-cards with live selected state, selectable canvas-theme roles or custom colors, optional images and multiple aggregated values. Filter multi-cards support 1–6 value columns, automatic/fixed/percent column widths and per-value column/row-span placement. Selection can be highlighted by background, border only, or both. Values support the multi-card renderers, data bars and conditional formatting; All/Clear can show totals and measures; and text fields have a right-click token menu. The same filter object drives editor, Presentation and exported webpages, the visual keeps non-selected choices available while filtering, and compact visual-filter tiles can be resized down to 30 pixels high.
    • Improved visual-filter authoring with a movable/resizable designer, preview-to-property navigation and the common property-group shortcut strip. Column count is now a maximum so fewer choices use the full available width. Dropdowns remain selectable, avoid an unnecessary side scrollbar and provide search for long lists; the compact date-range picker now lays out days correctly. Multiple visuals bound to the same filter highlight together, and valid measures from related sources are available to card-style filter values.
    • Fixed inherited presentation filters so separate filters on the same datasource column retain their stable identities and selection modes. Visual filters using Follow filter type now remain interactive and single-select for Dropdown filters in Presentation mode instead of becoming a combined multi-selection filter.
    • Added a repeatable Copy formatting painter to the right-click menu for tiles and graphics. Compatible targets are outlined, page tabs show compatible target counts, and formatting can be applied to multiple same-family objects across pages without replacing their data bindings or content. The normal Ctrl+C/Ctrl+V object clipboard can also paste complete editable tiles and graphics onto another page and remains reusable for repeated pastes.
    • Simplified object layer commands into Bring to front and Send to back submenus, with one-step forward/backward commands still available inside them. In edit mode, holding an action or hyperlink control selects its object without following the destination, making linked controls easier to move and format.
    • Added a Measure-workspace color picker that previews and inserts theme roles or fixed hex colors, plus the field context-menu template fields_pickcolor for building a variable-based color SWITCH measure. Canvas palette swatches and the dedicated eyedropper now remain active until a report color is sampled or the operation is cancelled.
    • Up and Down Arrow now scroll the active long text or Multi-card tile before falling back to the canvas viewport, so selected overflowing content can be read without using the scrollbar.
    • Presentation mode now starts on the page currently open in the editor instead of returning to the first page, and F11 toggles full screen on or off.
    • Pressing F now shows or hides the filter panel in Presentation mode and exported webpages without changing the saved filter values.
    • Compressed the Presentation and webpage-export top bar: page tabs remain on the first row, excess pages move under …, Zoom and Annotations are easier-to-open collapsed menus, and auto-hidden controls overlay the report instead of resizing it.
    • Presentation and web-export profiles now inherit the canvas editor's source and page filters by default, including their current values and page scope. Individual source, page and tile filters can be locked so they remain active as authored report constraints without appearing as viewer controls; the previous manual export-filter setup remains available when inheritance is disabled.
    • Added complete Week labels and a Quarter scale to Gantt timelines. Exported Gantt views now retain resource view, level collapse, visible columns, read-only task information and the saved hidden-toolbar state.
    • Improved Query workspace manual-table editing and resized the date picker into a compact, responsive calendar that remains usable in narrow windows.
    • Fixed the enterprise updater's download-progress dialog and added direct release-note access before installation plus a release-note prompt the next time Qanvas opens after a successful upgrade.
    • Restyled the update checker with the active Qanvas theme and branded the enterprise install, upgrade, progress and completion dialogs with the Qvitr visual design.
    • Fixed elevated update launches so the Qvitr Enterprise installer is restored and brought in front of other application windows instead of opening unnoticed behind them.
    WEEK42

    12–18 October 2026

    Manual enterprise updates and safer GitHub releases

    • Simplified Report Grid to one rectangular A1 cell model. The former dedicated column-header, row-label and corner cells were removed; every grid cell now supports the same content, formatting and formula behavior, while filters remain on the row and column axes.
    • Added a user-initiated Check for updates command to Qanvas, Excel and PowerPoint. Enterprise installations never check automatically.
    • Added a dedicated GitHub qvitr-update.json manifest with separate Qanvas file and MSI installer versions, setup URL, release URL and SHA-256 hash.
    • Added confirmation, download progress, hash checking, Authenticode presence checking and elevated setup launch to the shared Qanvas updater.
    • Added a one-command GitHub release script that can build, sign, stage, validate and upload Qvitr Enterprise, with validation-only, draft and reuse-existing-build options.
    • Strengthened release validation so the update manifest, MSI and bootstrapper must agree with the requested version and installer hash before upload.
    • Updated installer guidance to require a new three-part MSI version for each release; signing certificates do not require the installer version to remain fixed.
    • Added direct Qanvas source relationships with multi-field keys and explicit Dimension or Measure lookup roles. Linked dimension fields can group tables, form matrix axes, and drive chart categories/groups without physically expanding the primary detail table. Source and page filters on a Dimension master propagate to directly linked fact sources. Tables, matrices, charts, and the full Chart Designer can use measures from a linked, pre-aggregated source. The relationship editor reports loaded-data cardinality and requires a unique Dimension key.
    • Fixed folder and single-file webpage exports so source relationships remain in the offline snapshot. Exported visuals now calculate linked fields/measures and propagate filters from Dimension master tables in the same way as Presentation mode.
    • Fixed native Mini DAX source-field parsing so physical names containing underscores, including accounts_receivable, are aggregated correctly instead of being truncated at the first underscore.
    • Added measure-driven Report Grid crossfilters. Row and column filters can use {{measure:name}} to resolve a scalar from the effective cell source before filtering the displayed measure; explicit and legacy parameter tokens remain supported.
    • Corrected the MiniDAX function reference so CAST target types and DATEPART part names use quoted text, with working numeric-conversion and week-number examples in both native and web Measure workspaces.
    • Added Find unused to Measure workspace Tools. It marks measures with neither formula dependants nor references in the current Qanvas document, opens each candidate for review, and deliberately leaves deletion manual; calculated columns are excluded from the cleanup scan.
    • Canvas parameters now resolve inside MiniDAX measures during validation, matrix testing, charts, Presentation and webpage output. The Measures function reference lists parameters, and typing {{ opens parameter autocomplete.
    • Replaced free-text chart format fields with the same preset/custom format selector in both Chart Designer and the chart Properties pane.
    • Added Claude Code as a Qanvas AI CLI provider. Codex and Claude sessions are now provider-specific, Qanvas verifies workspace write access before every turn, and the built-in setup guidance distinguishes Windows folder permissions from ChatGPT Work access.
    • Report Grid cells now keep text on one clipped line by default so content cannot unexpectedly enlarge rows. Wrapping can be enabled per cell or multi-cell selection, and vertical alignment supports top, middle, or bottom with middle as the default.

    • Added the native Gantt tile with embedded editable task data or linked read-only data. It supports task IDs, projects/groups, owners, status, progress, milestones, descriptions and dependencies; an optional published Gantt datasource can drive other visuals and normal Presentation/Web filters.
    • Expanded Gantt interaction with direct table editing, sortable/resizable columns, column filters and menus, collapsible groups, bar drag handles, date tooltips, timeline options, a movable/resizable rich-description editor, pure-Gantt view, Present-mode editing and webpage interaction. Selected tasks and dependency paths can be highlighted.
    • Added interactive checklists to Gantt task descriptions, including a toolbar action, -- + Space quick entry, normal bulleted sublists, explicitly nested checklists, saved checked state, and completed / total counters in the editor, task table and interactive description preview. Description previews remain open while the pointer moves into them or checks an item, close when the pointer leaves, and hide while the full description editor is open.
    • Presentation settings now hide disabled pointer and annotation tools consistently in normal Present view, including its right-click menu and annotation shortcuts.
    • Added theme/manual formatting for Gantt table areas, groups, bars, progress, status badges, dependency arrows and labels. Project, owner and status registries provide reusable dropdown values and colors.
    • Reworked formatted text so the canvas editor is the primary editor. Selection/caret formatting now includes font, size, color, bold, italic, underline, lists and Normal/H1/H2/Quote styles, with less-common insert commands in a compact menu.
    • Expanded Qanvas AI with CLI, external-workspace and manual-support-pack flows, queued requests, file/screenshot attachments, activity messages, resizable panes and stronger host/feature validation. Copilot's slower automatic feature audit and repair turns can be disabled independently of structural validation.
    • Added native-Gantt and custom-SVG guidance to the exported AI skill, including checks that requested images, links, timelines and theme bindings really exist instead of being claimed in text.
    • Added connection-level API parameters shared by every API on a connection. Effective values now follow connection defaults → API defaults → Excel/Canvas/Query launch values, without writing temporary caller values back to saved definitions.
    • Expanded Measure workspace with reference auditing, invalid-formula checks, rename propagation into dependent measures and Canvas objects, a compact Tools menu, progress feedback, folders, a complete searchable function reference and expression helper. Date functions including TODAY() are supported by Canvas visuals.
    • Added Reset Main source, A4 portrait page presets, a 2×4 blank report-grid default, reusable palette roles, themed scrollbars and the opt-in Qvitr experience mode with alternate labels and artwork.

    • Added themed AI Assistant actions for a focused prompt, a redacted support pack and a reusable product-reference skill. Corrected offline webpage export packaging so SVG graphics include their required runtime asset.
    • Improved CSV API response-shape aliases/exclusions and themed the selected-sheet, parameter, source-update and local-import dialogs.
    • added presentation mode to Canvas Web so the current canvas fills the entire window, hides the ribbon and tabs, and disables editing and selection. The Escape key returns to normal mode.
