    Changelog

    User-visible changes are grouped by calendar week. Dates identify the Monday-to-Sunday period in which the work was completed.

    Week 36

    31 August to 6 September 2026

    • Expanded Query Web with alias-aware completion, table aliases, selected-column SQL generation, value and advanced filters, editable SQL Server results, Grid/JSON/Parsed SQL/Messages tabs, multi-line indentation, and 1,000-row defaults.
    • Expanded API Web with reusable connection/authentication settings, SecretManager tokens, submitted/JSON request views, resizable panes, response shaping, flatten-path selection, aliases, exclusions, formats, and sortable data previews.
    • Added Measure workspace support for measures and calculated columns, templates, validation, parameters during Load data, custom formats, drag/reorder matrix wells, crosstab testing, and resizable panes.
    • Improved Canvas Web with dockable panes, subtle four-corner resize handles, advanced Table/Matrix ordering and formatting, consistent visual-builder layout, Chart Web integration, Canvas-only recent files, and cleaner exported images.
    • Reorganized the Excel ribbon around Query Web, Canvas Web, API Web, Measures, and Load selected while retaining legacy tools for migration testing.
    • Refined Chart Web with collapsible Data and Options panes, movable legends, clearer color controls, and resize controls for pie, doughnut, gauge, and treemap visuals.
    • Added Canvas basic-value and Top/Bottom N filters, including visible selected values and type-safe comparisons for numeric fields.
    • Added editable manual request JSON to API Web and persisted it with saved API definitions; also improved compact fields and collapsed-pane labels.
    • Updated the PowerPoint add-in to prefer the latest Canvas Web build, use the WebView parameter editor, and avoid blocking when Canvas is closed with the window close button.
    • Added document-level Canvas datasources with one protected Main source, reusable global sources, per-tile source selection, and shared global parameters; existing page queries migrate automatically and Excel _control values remain authoritative.
    • Added Canvas source and tile filters that operate on loaded data, retain independent filters per visual, and identify the referenced tile.
    • Added Canvas graphics with formatted text, resizable lines and rectangles, layer ordering, alignment guides, and routed connectors that remain attached while tiles move.
    • Expanded Matrix tiles with ordered row hierarchies, tabular and Excel-style outline layouts, top or bottom parent subtotals, optional blank rows and +/- groups, aligned value headers, and separate detail/subtotal typography.
    • Expanded Card/KPI tiles with smaller layouts, configurable caption templates and typography, rounded corners, transparent backgrounds, and optional border removal.
    • Added global Canvas header-tag visibility, improved recent-file labels, and corrected Canvas shutdown so closing the last window releases the Debug process and WebView resources.

    Week 35

    24 to 30 August 2026

    • Improved Chart Designer field selection, automatic categories, validation messages, waterfall layouts, scatter behavior, treemaps, doughnuts, Sankey validation, and responsive settings.
    • Expanded hierarchical parameters, list formatting and ordering, _control persistence, and shared Excel/Canvas/PowerPoint behavior.
    • Added structured connection editing and file-based CSV/text sources for Mini SQL.
    • Simplified legacy Canvas property editors and improved page backgrounds, chart-setting persistence, filters, and PowerPoint help.

    Week 34

    17 to 23 August 2026

    • Added and published the documentation site and Excel Help entry point.
    • Unified parameter storage and substitution across Excel, Canvas, and PowerPoint.
    • Improved API empty-response handling and Query Tool return behavior.
    • Added persistent Query Tool column visibility, schema-aware search, and Excel COM cleanup fixes.
