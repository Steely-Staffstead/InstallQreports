    Graphics and layout

    Graphics add structure and explanation without requiring a datasource. Qanvas supports formatted text, lines, rectangles, ovals, connectors, images, and SVG content alongside normal tiles.

    Graphics

    • Text graphics support the same rich-text concepts as Text tiles and Gantt descriptions: headings, colors, bullets, checklists, links, editable tables, code/diagram blocks, and compressed inline images.
    • Use safe formatted HTML in a Text tile or Text graphic for a one-off, mostly static composition such as outlined callouts, boxes with arrows, code panels, or a simple flow diagram. Use SVG instead when geometry must scale precisely or bind to data, separate canvas shapes and connectors when parts must remain independently movable, and Multi-card for a repeated data-driven layout.
    • Insert > Date countdown adds date-driven text without a datasource or measure. Choose a target date and configure separate text for a future date, the target day, and a passed date. Use {days} for the absolute number of days or {date} for the formatted target date. While editing, it remains a readable and copyable function such as datecountdown("2026-10-11", "Neste om {days}", "I dag", "Ferdig"). The dialog formats it as a subtle wrapping code chip. Normal, presentation, and exported views show only the recalculated result.
    • Selecting an inline image opens an image-only floating toolbar above or below it. Set width, align left/center/right, compress, remove, or drag a corner handle while preserving aspect ratio. Clicking text returns to text editing.
    • Lines and shapes support color, thickness, solid/dotted/dashed styles, transparency, fill, rounding, movement, and resizing.
    • Connectors attach to tile edges and follow the connected tiles when they move.
    • Connector routing, endpoints, arrow size, line style, and layer order are configurable.
    • Pictures and SVG graphics can be embedded so the report remains portable.
    • Custom SVG created from source uses the Manual template. In document JSON, keep the standalone element only in nested svgGraphic.svgCode and explicitly set nested svgGraphic.template to lowercase manual.
    • Open SVG designer… shows a collapsible reusable-template gallery and a full Custom SVG workspace. Analyze SVG discovers text components, editable shapes, likely category labels and a horizontal date axis with a Today/I dag marker. Detected text can be edited in place with font, size, weight, color and link controls; named shapes expose fill, border, border width, position and supported geometry. Paired horizontal rectangles are recognized as a progress track and fill even without field metadata, so the fill width can be changed directly in Progress fill > Position and size. Explicit data-qanvas-field and data-qanvas-label attributes remain the most reliable choice for other editable shapes. Use as category slot is separate from editing: only checked slots are filled, in order, with unique values from the selected source column. The date marker can follow the current date, a fixed date, a source field or a parameter between a configured start and end date. Click a detected item in the preview to open, scroll to, and highlight its controlling component or date-marker editor. Duplicate copies normal components, while Duplicate marker copies the label, badge and line and adds an independently configured dynamic marker rather than only cloning its text. The preview uses the same tile frame and render path as the applied graphic, including the final tile aspect ratio. Raw SVG source, component editing, colors and data bindings all live in the designer rather than being duplicated in Properties. Right-click an editable text or date-label input, or use its ＋ insert button, to open the searchable field/measure/parameter token lookup. The catalog includes related-source measures when relationships make them available to the SVG tile.
    • CanvasWeb/examples/manual-svg-timeline.svg is a complete editable timeline example with month/week labels, category lanes, a Today marker, theme colors and named components.

    Multi-card tiles

    Use Add tile > Multi-card when the same small information layout should be repeated for countries, projects, milestones, customers, or another dimension. Open the designer and choose a Group by column. Add any number of source fields or measures to the Values well and arrange them in one to six columns. Raw source fields support First, Sum, Average, Min, Max, and Count; measures are evaluated in the filter context of each repeated card.

    Each value column can use Auto / remaining, Percent, or Fixed width. Auto columns share space that remains after fixed-pixel columns. Percentage values act as responsive proportions and are normalized with the Auto columns; for example, 15% + Auto + 25% produces a 15 / 60 / 25 layout. Prefer percent/Auto for presentation layouts that must resize, and use fixed pixels only for compact columns such as dates, icons, or status labels.

    Each value also has a Placement section. Leave Column on Auto flow for the normal left-to-right layout, or pin an image, data bar, or other value to a numbered column. Height can occupy one to six rows or the Full column; the remaining values flow densely through the other available cells. For example, use two value columns, pin an image to column 1 with Full column height, and leave three text values on Auto flow to stack them in column 2.

    The value's Align setting applies to both its value and caption. Open Cell display on a value to render it as a number/text value, image, badge, icon, or data bar. Badge and icon colors can follow a theme role, indicate positive/negative status, or use a custom color. Each value also exposes the same Data bar / bullet graph and Conditional formatting controls used by table and matrix columns, including comparison fields/measures, value-strength colors, negative-value color, emphasis and threshold icons. Format using can point to a different numeric field or measure while the displayed value remains text; for example, show date_diff while colors are calculated from date_diff_days. A value can also drive a thin card Color band on the left, right, top, or bottom edge. The band can use the conditional result or a separate field/measure that returns a hex color or theme role.

    Heading and supporting-text templates support {{group}}, {{field:Amount|Sum}}, {{measure:Sales}}, and {{parameter:Year}}. Card captions support the same tokens. Right-click a heading, supporting-text, or caption input to insert a field, measure, parameter, group value, or the upper/lower text functions without typing the token. The menu also inserts an editable datecountdown(...) expression using today's date as a starting point. Each value initially shows only its field/measure, aggregation and caption; open More for format, alignment, placement, cell display, data bars and conditional formatting. Card placement uses CSS grid with either a fixed number of cards per row or an automatic minimum width. Use Show heading instead of an empty or whitespace heading when only supporting text is needed. In the designer preview, click a heading, supporting text, value, or value caption to scroll to and focus its corresponding setting. Text and number boxes update the preview when focus leaves the box, avoiding a full preview refresh for every typed character; selects, checkboxes, and color controls remain immediate. Colors and borders may inherit the Qanvas theme or be set explicitly. No background (transparent) removes the repeated cards' fill while retaining theme-based text and accent colors. Border sides can show all edges, only the top and vertical sides, only horizontal separators, or no inner card border. Border width supports fractional values such as 0.25 and 0.5 px for subtle dividers. Use a Multi-card rather than a rich-text table when rows must be generated dynamically from data; use a rich-text table for a small, manually authored piece of narrative content.

    When a Multi-card is selected on the canvas, Up Arrow and Down Arrow scroll its card body when it overflows. The same behavior applies to a long Text box configured for internal scrolling.

    Arrange a page

    Use alignment guides for visual placement and the Properties pane for exact coordinates and dimensions. Multi-selection is useful for moving, aligning, copying, or deleting a group of objects. Hide design handles and type tags when reviewing the finished layout.

    Pages support preset or manual dimensions, including widescreen presentation and A4 portrait, plus page colors and background images. Tiles can use rounded corners, transparent surfaces, optional borders, and explicit layer ordering. Text objects clip at the box edge by default for a clean canvas. Choose Scroll inside box for long, webpage-like content; editing follows the same scroll container.

    Themes

    The Canvas theme controls page and visual roles such as surface, text, headers, grid lines, and data-series palettes. Individual visuals can inherit the theme or use explicit overrides. Keeping theme roles separate from chart-series colors makes a report easier to restyle consistently.
