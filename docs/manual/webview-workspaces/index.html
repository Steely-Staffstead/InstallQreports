    WebView workspaces

    QReports now uses a shared WebView2 host for its main interactive tools. The web workspaces use the same visual language, pane behavior, keyboard conventions, connection objects, parameters, and result formatting while keeping the established Excel storage formats.

    Common layout

    • Left panes contain sources, fields, saved objects, or document structure.
    • The centre is the main editor or design surface.
    • Right panes contain properties and supporting tools.
    • Side panes can be resized, collapsed to their edge, and reopened without losing their width.
    • Long-running actions show a loading state. Render-only Canvas refreshes remain off screen.
    • New query and API previews default to 1,000 rows. Existing saved limits are preserved.

    Query Web

    Use Query Web to browse schemas, build SQL, edit supported SQL Server tables, run parameterized queries, and inspect Grid, JSON, Parsed SQL, and Messages output. Table and column context menus provide query generation, aliases, distinct-value filters, formatting, column visibility, and previews. The SQL editor supports alias-aware completion and Tab/Shift+Tab indentation for one or several selected lines.

    API Web

    API Web separates reusable connections from endpoint definitions. Connections hold the base URL, authentication/workflow, default headers, timeout, and SecretManager references. Endpoints hold method, relative path, request parameters/body, pagination/loop behavior, and response shaping. Use Submitted request to inspect the actual HTTP request without QReports metadata, and Data/Raw response to diagnose the result.

    Measure workspace

    Measure workspace creates and validates Mini DAX measures and calculated columns. Right-click a source field for formula templates. Measures support built-in or custom number formats and can be tested in a matrix by dragging fields into Rows, one Columns field, and Values. Load data resolves the current workbook/Canvas parameters before executing the source query.

    Canvas Web

    Canvas Web builds pages from table, matrix, chart, card, text, and picture tiles plus text, line, rectangle, and connector graphics. Main and global data sources belong to the document; each data-bound tile selects a source, while global parameters are available to every source. The report structure and properties panes dock at the sides. Source and tile filters operate on loaded data. Table and Matrix designers use Fields → selected objects/options → Preview, including ordered row hierarchies and formatted subtotals. Chart tiles open Chart Web through Design. Returning to Excel or PowerPoint stores the definition with the rendered image.

    Supporting web forms

    Parameters, connections and secrets, logs/status, selected-sheet loading, and PowerPoint Canvas-shape selection use focused WebView routes. Secret values are stored through the existing SecretManager and are represented in definitions by tokens instead of clear text.

    Legacy access

    The Excel ribbon keeps Legacy tools during the migration period. Use these entries only when comparing behavior or maintaining an older workbook. New workflow buttons open the WebView versions.
