    Formula Helper

    Formula Helper is the reference and code-generation pane for QRep Excel Code. It helps you find a keyword, supply valid options, preview the resulting syntax, and insert it into Excel.

    It is not intended to be the primary tutorial for the language. Start with QRep Excel Code to understand how connection, query, and output rows work together, then use Formula Helper while building a report.

    Open the helper

    Choose QRep > Formula Helper to show or hide the pane on the right side of Excel. The pane stays close to the worksheet so you can inspect a report definition and insert generated code at the active cell.

    Choose what to create

    The workflow selector organizes the supported builders into four groups.

    Mode Available templates
    Report output Table, Dynamic table, Pivot table, Summary, Subtotal
    Companion row Column / measure row, Crossfilter row, Parameter row
    Control setup Parameter setting, Template report setup, Sheet password
    Raw keyword Direct access to the available keyword definitions

    Selecting a template displays a short explanation, a structure preview, and only the options relevant to that keyword.

    Look up reference information

    Use the reference browser and search box when you need to check a function, option, filter operator, or example. This is the quickest use of Formula Helper: look up the exact syntax without leaving Excel or changing the current worksheet definition.

    The helper can also load the active Excel definition, making it easier to inspect or adjust code that is already present.

    Generate report output code

    The output builders produce correctly ordered options for:

    • table, including group, filter, sort, options, and top rows;
    • dtable, for structured Excel table output;
    • ptable, for pivot-style output;
    • summary, for compact value and measure rows;
    • subtotal, including groups, filters, sorting, and outline options.

    For example, selecting Report output > Dynamic table and entering a group, filter, and row limit can produce:

    dtable;group(continent);filter(year=2026);toprows(20)

    The generated syntax is shown in the preview before it is inserted.

    Table helper

    The dedicated table helper is designed for complete table definitions, not only the first keyword cell. Use it to:

    • choose output fields and their order;
    • assign aggregations and display labels;
    • create an explicit header row;
    • create footer values such as $sum, $count, and $avg;
    • add footer labels and outline behavior;
    • preview the worksheet structure before insertion.

    An inserted template can look like this:

    ABCD
    7table;group(continent)continentpopulation
    8+headerCONTINENTPOPULATION
    9+footer;outlinelabel(SUMMARY)$sum

    Subtotal helper

    Use the subtotal helper to generate hierarchical output without manually assembling every template row. It supports grouping levels, selected measures, labels, headers and footers, Excel outline behavior, and initially collapsed groups.

    Preview the structure before insertion. Check that the grouping order runs from the outer group to the detailed level and that aggregate values are placed in the intended output columns.

    Companion rows

    The Column / measure row builder supports field or measure names, filters, aggregation, units, labels, and options. Its aggregation choices include SUM, AVG, MIN, MAX, FIRST, and LAST.

    The Crossfilter row builder creates per-column filters. The Parameter row builder creates parameter/value pairs for report code.

    Control-sheet setup

    The Control setup mode generates rows intended for _control:

    Template Generated purpose
    Parameter setting set | parameter | value | user input | advanced JSON
    Template report setup setreport | template | report | parameter/value pairs
    Sheet password setpassword | sheet | password

    For advanced parameter input types, list lookups, tree levels, formatting, text parsing, and sheet scope, use Parameter Manager after creating the base setting. See Parameters.

    Insert safely

    1. Select the target cell or existing definition in Excel.
    2. Choose the mode and template.
    3. Fill in the displayed options.
    4. Review the syntax or worksheet preview.
    5. Use Insert into Excel only after confirming the active position.
    6. Load the selected line to test the result.

    Use Load from Excel when modifying an existing definition. This reduces the risk of recreating options that are already stored in the worksheet.
