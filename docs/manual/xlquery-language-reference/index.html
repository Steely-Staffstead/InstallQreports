    xlQuery language reference

    This reference reflects the commands and syntax accepted by the current xlQuery scanner, output engine and Formula Helper. Parentheses are the preferred form; some older expressions also accept brackets.

    Report and output commands

    Command Purpose
    table Standard report table.
    tablea Alternate table token supported by the table engine.
    dtable Structured/dynamic Excel table output.
    ptable Pivot-style output.
    summary Compact KPI or measure summary.
    subtotal Grouped detail output with header/footer rows and Excel outline.
    load Loads an output definition.
    chart, graph Chart output tokens supported by the execution engine.

    Companion and control rows

    Command Purpose
    column Field or measure definition with optional aggregation, label, filter and unit.
    crossfilter Applies a filter expression to an output column.
    parameter Parameter/value pairs in report code.
    set Parameter setting on the control sheet.
    setreport Template-sheet and report-sheet setup.
    setpassword Sheet protection configuration.
    + Subtotal template row marker.

    Source and query tokens

    sql, q, query, conn, connspec, model, powerquery and file are recognized source/query tokens.

    Functions and clauses

    Syntax Purpose
    filter(...) Filters rows. Comma-separated conditions are combined with AND.
    group(...) Ordered grouping keys.
    sort(...) Sort keys with optional ASC or DESC.
    toprows(...) Positive maximum number of rows. toprows=n is also accepted.
    options(...) Output options such as LeftColumn=3.
    agg(...) SUM, AVG, MIN, MAX, FIRST or LAST.
    label(...) Display caption.
    unit(...) Non-zero numeric scaling value.
    offset(...) Relative summary output position.

    Directives

    • noheader suppresses generated headers where supported.
    • nocrossfilter prevents crossfilter from affecting an output or column.
    • outline creates expanded subtotal outline groups.
    • outlinec creates collapsed subtotal outline groups.
    • header, header1, … and footer, footer1, … define subtotal template rows.
    • {{parameterName}} inserts a workbook parameter value at execution time.

    Filter syntax

    • Comparisons: =, <>, >, >=, <, <=.
    • OR values in one field: region=1|2|3.
    • Range: account=3000-3999.
    • Wildcards: * and %.
    • Empty values: NULL and NOT NULL.
    • Multiple comma-separated conditions are combined with AND.

    Subtotal example

    subtotal;group(region,country);filter(year={{currentyear}})
+ | header1          | region
+ | footer1;outlinec | region
+ | footer           | label(SUM)

    The Formula Helper can generate and insert the complete multi-row subtotal template.
